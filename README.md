# 豆谱 DOUPU

把照片变成真正可以照着拼的图纸，或者从一块空白豆板开始自己绘制。

豆谱完全在浏览器本地工作。照片模式提供取景、配色和背景处理；自由画板提供画笔、橡皮、区域填充、直线、矩形色块与取色。两种方式共用效果图、制作图纸和导出链路，也可以保存为 `.doupu` 项目后再次打开继续制作。

## 功能

- 照片转图与自由画板两种制作方式可随时切换，彼此状态独立保留
- 自由画板支持画笔、橡皮、区域填充、直线、矩形色块、取色、撤销、重做和清空
- 可选 MARD 221 或 Hama Midi 色盘；更换画板色盘时按感知色差重新映射已有豆色
- 可选小号 52 × 52、标准 74 × 74（默认）和大号 104 × 104；可在裁切铺满与完整缩放之间切换，并直接拖动、缩放原图控制最终取景
- 通过 CIEDE2000 感知色差匹配实体色盘，并支持 Floyd–Steinberg 抖动
- 可从画面上沿和两侧识别主要背景色，并通过清理范围移除阴影、压缩噪点和内部同色区域
- 效果图模拟单颗拼豆；网页图纸预览省略格内文字以保持流畅，导出的 PNG/PDF 使用实际豆色并以黑白高对比文字标注材料色号
- 制作图纸会裁掉外围未用行列，只保留实际占用区域；每 5 格加粗辅助线仍按图案在原板上居中时的绝对坐标排布
- 单张 PNG 图纸带完整行号、列号；PDF 采用横向纸张自动分页，相邻页重复 2 行与 2 列，并附总览和备料清单
- `.doupu` 项目同时保存照片工作区、画板工作区、当前制作方式与全部参数，可导入后选择任一方式继续制作
- 图片在本机解码并由 Web Worker 处理，不上传到服务器
- 支持拖放、粘贴和文件选择；输入最大 40 MB，长边会在本地压缩至 2048 px
- 桌面与移动端自适应

## `.doupu` 项目格式

`.doupu` 是版本化的 JSON 项目文件，当前版本为 `1`。它不是最终打印格式，而是类似 PSD 的可继续编辑源文件：

- `photo` 保存原图、取景、尺寸、色盘、颜色数量、抖动和背景设置
- `board` 保存板型、色盘与逐格豆色；格子使用色号字典加 `rle-v1` 游程编码，避免重复颜色造成冗余
- `activeWorkflow` 记录保存时正在使用的制作方式
- 文件只在浏览器本地读取和生成，不上传服务器

最终交付仍使用横向 PDF 或带行列号的 PNG；需要返工或换一种方式继续制作时使用 `.doupu`。

## 本地开发

```bash
npm install
npm run dev
```

检查与构建：

```bash
npm test
npm run build
```

## 技术结构

- React 19 + TypeScript + Vite
- Web Worker 负责缩图后的调色板筛选、色差匹配和抖动
- Canvas 负责效果图、图纸和导出画布
- 统一 `PatternResult` 让照片转换与自由画板共用 PDF/PNG 导出
- jsPDF 在需要导出时动态加载；上传和导出均无需后端

## 色号说明

默认材料编号采用 MARD 221 色 A–H/M 体系，例如 H2 为白色、H7 为黑色；也可切换到 Hama Midi 数字色号。HEX 仅用于屏幕配色，不代表实物测量值；购买前请核对手中的实体色卡与批次。
